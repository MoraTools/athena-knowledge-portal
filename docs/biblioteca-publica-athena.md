# Cómo usar la biblioteca pública de Athena

Puede consultar los artículos públicos de Athena sin crear una cuenta ni iniciar sesión.

## Encontrar un artículo

1. Abra **Guías**, **Herramientas** o **Actualizaciones** desde el menú.
2. Use **Buscar en Athena** para encontrar un tema por su título, contenido o etiquetas.
3. Abra el resultado para leer el artículo completo.

La biblioteca y la búsqueda muestran solo el contenido disponible para usted. Al ingresar con una cuenta, también verá los artículos publicados para el equipo.

## Copiar el contenido o guardar un PDF

Use **Copiar página** para copiar el texto Markdown del artículo.

Use **Exportar PDF** para guardar una versión del artículo. Si el artículo incluye un PDF original, puede abrirlo desde el lector. Los artículos cuyo contenido es un PDF muestran ese archivo directamente.

## Acceder al contenido del equipo

Seleccione **Ingresar** si tiene una cuenta de Athena. Después de iniciar sesión, volverá a la página que estaba consultando.

Los archivos de **Descargas** requieren una cuenta. Si necesita acceso o ayuda con su contraseña, contacte al administrador de Athena.
